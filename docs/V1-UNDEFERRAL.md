## Reconciliation rules

1. A current authoritative document may say `deferred` only for a hard external action (for
   example signed-in public Workshop publication), never for accepted implementation work.
2. `Implemented` means the owning runtime path exists; it does not erase a native/human evidence
   gate.
3. A stronger implementation may supersede an old positive shape, but the ledger must name the
   replacement and show that its player-facing purpose survives.
4. Historical research remains unchanged except for a supersession banner when needed. Canonical
   truth is repaired in `VISION.md`, `README.md`, `docs/`, `TESTING.md`, and the current brief audit.
5. Any newly found positive deferral is appended here before implementation or reconciliation, so
   it cannot disappear into a prose diff.
